# Question

Solve this question on: `terminal`

1.  Identify the raw unformatted disk attached to your system (hint: use `lsblk` and `blkid`).
2.  Format the disk with the **ext4** filesystem.
3.  Mount the newly formatted disk to `/mnt/backup-black`. (Ensure you create the mount directory `/mnt/backup-black` first).
4.  Create an empty marker file named `completed` directly inside your mounted directory (`/mnt/backup-black/completed`).
