# Question

Solve this question on: `terminal`

Your team has added a new 2GB raw secondary disk to the server. Your task is to partition this disk using a GUID Partition Table (GPT).

1. Find the newly attached 2GB raw disk using standard discovery commands.
2. Initialize a GUID Partition Table (GPT) on this device.
3. Create a single primary partition starting at sector 2048 (1MiB alignment) and ending at 1GiB (1024MB).
4. Leave the partition unformatted and unmounted.
