# Persistent Remote Mounts and NFS Repair

QEMU lab for the LFCS course: fix a broken NFS export, then write persistent `/etc/fstab` lines for an NFS mount and an SSHFS mount. One virtual machine plays both the server and the client.

## Run

```bash
astrona run --git git@github.com:astrona-io/ATS004.git -c sections/section-020/module-02/labs/lab-02
```
