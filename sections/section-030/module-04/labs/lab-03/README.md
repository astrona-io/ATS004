# RAID Stop, Reassemble and Wipe

QEMU lab for the LFCS course: stop a RAID 1 array, put it back together with `mdadm --assemble`, and wipe the leftover RAID label from a spare disk with `--zero-superblock`.

```bash
astrona run --git git@github.com:astrona-io/ATS004.git -c sections/section-030/module-04/labs/lab-03
```
